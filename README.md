# 🎵 GlassPlayer By Sasuu

A modern Android music player built with Jetpack Compose.

## ✨ Features

- 🎵 Local music library
- 🔎 Search
- 📂 Folder browsing
- 📑 Playlists
- ▶️ Background playback
- 🎚️ Equalizer
- ⏱️ Sleep timer
- 🎨 Glassmorphism UI
- 🎧 Media3 / ExoPlayer
- ⚡ Fast and responsive interface
